# Verification notes

The numeric verifiers in verify/ parse the published manuscript and Supplementary
Information and check each reported value against the derived data.

Scope: aggregate results are reproducible from the files in supplementary_data/.
Individual-level data and the modelling matrix are not included (ChiCTR2500111002,
IPD sharing: No), so a fresh clone cannot re-fit the published models.

Environment: see requirements.txt for package versions (Python 3.9+).

Contact: the corresponding author.
