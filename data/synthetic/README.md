# SYNTHETIC DATA — for pipeline demonstration only

**Not patient data. Not derived from patient data. Not study results.**

Every value in this directory was generated by a seeded random number
generator (`tools/make_synthetic_data.py`, seed 20260101).  The real
tables were consulted **only** to copy column names; no real cell value
was read into this dataset.

The individual-level analysis dataset is not publicly available
(ChiCTR2500111002: *IPD sharing: No*); see the top-level README.

Purpose: let a reader run the code end-to-end and confirm that the
pipeline executes.  **Numbers computed on these files are meaningless** —
they will not, and must not, match the paper.
