# Supplementary data

Twenty aggregate result tables underlying the analyses reported in the manuscript:

> **Habitat selection by clinical endpoint predicts nodal status in prostate cancer**

Five of them (Supplementary_Data_01 to 05) are also supplied with the manuscript as
Supplementary Data 01-05; the remaining fifteen are provided here only. The five printed
tables (S5, S12, S16, S24, S25) appear both in the Supplementary Information and in this
directory.

| File | Content | Supplied with the manuscript |
|---|---|---|
| `Supplementary_Data_01.csv` | Incremental value of the combined model (AUC, ΔAUC, IDI, continuous NRI, by cohort) | Yes (Supplementary Data 01) |
| `Supplementary_Data_02.csv` | Decision-curve analysis in clinical terms (case numbers and net benefit by threshold) | Yes (Supplementary Data 02) |
| `Supplementary_Data_03.csv` | Recalibration and decision-impact analysis | Yes (Supplementary Data 03) |
| `Supplementary_Data_04.csv` | Sensitivity analysis excluding the manually corrected target regions | Yes (Supplementary Data 04) |
| `Supplementary_Data_05.csv` | Subgroup analyses (ISUP grade group, PSA stratum, field strength) | Yes (Supplementary Data 05) |
| `TableS11_habitat_volume_fractions.csv` | Habitat volume fractions by nodal status | No (repository only) |
| `TableS12_external_robustness_and_pairwise.csv` | External robustness and pairwise comparisons, printed as Table S12 | No (printed table) |
| `TableS15_regression_pN1.csv` | Univariable and multivariable regression for pN1 | No (repository only) |
| `TableS16_alternative_clinical_comparators.csv` | Alternative clinical comparators, printed as Table S16 | No (printed table) |
| `TableS19_deep_learning_comparator.csv` | Deep-learning comparator, full results | No (repository only) |
| `TableS1a_acquisition_summary.csv` | MRI acquisition parameters by institution | No (repository only) |
| `TableS1b_scanner_models.csv` | Scanner models and field strengths | No (repository only) |
| `TableS24_supplementary_models.csv` | Supplementary models, information-matched comparisons, printed as Table S24 | No (printed table) |
| `TableS25_model_features.csv` | All-habitat model: 25 features and coefficients, printed as Table S25 | No (printed table) |
| `TableS2_habitat_profiles.csv` | Habitat radiomics profiles (H1-H5) | No (repository only) |
| `TableS3c_internal_indices.csv` | Internal clustering indices by K | No (repository only) |
| `TableS5_delong_p_values.csv` | Pairwise DeLong comparisons, printed as Table S5 | No (printed table) |
| `TableS6_whole_tumour_radiomics.csv` | Whole-tumor radiomics comparator analysis | No (repository only) |
| `TableS8_habitat_pipeline_technical_details.csv` | Technical details of the habitat pipeline | No (repository only) |
| `nnUNet_training_log.txt` | nnU-Net training log | No (repository only) |
