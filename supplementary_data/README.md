# Supplementary data

Twenty aggregate result tables underlying the analyses reported in the manuscript:

> **Habitat selection by clinical endpoint predicts nodal status in prostate cancer**

Five of them (Supplementary_Data_01 to 05) are also supplied with the manuscript as Supplementary Data 01-05;
the remaining fifteen are provided here only. The five printed tables (S5, S12, S16, S24, S25) are given both in
the Supplementary Information of the manuscript and in this directory.

| `Supplementary_Data_03.csv` | Recalibration and decision-impact analysis | 是（Supplementary Data 03） |
| `Supplementary_Data_04.csv` | Sensitivity analysis excluding the manually corrected target regions | 是（Supplementary Data 04） |
